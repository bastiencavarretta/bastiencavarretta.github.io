In order to customize references in this folder, add custom features, links, pdfs, images, arxive, code ..
On example:

`@article{cavarretta2026complexity,
  ...
  abstract  = {We study complexity guarantees for...},
  arxiv     = {2601.12345},
  pdf       = {complexity_riemannian.pdf},
  code      = {https://github.com/...},
  bibtex_show = {true},
}`
